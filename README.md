# ha-addons

Home-Assistant-Add-on-Repository von Cyborg11.

## Installation

*Einstellungen → Add-ons → Add-on-Store → ⋮ → Repositories* → `https://github.com/Cyborg11/ha-addons` hinzufügen.

## Add-ons

| Add-on | Beschreibung | Stand |
|---|---|---|
| `pc_companion_hub` | Hub + PWA für [PC-Companion](https://github.com/Cyborg11/PCCompanion) (Dashboard, Wake-on-LAN) | 0.2.1 |

HA installiert immer den Stand von `main`; Updates erscheinen nur, wenn `version` in der `config.yaml` des Add-ons erhöht wurde. Nie direkt auf `main` committen – Branch + Pull Request.
